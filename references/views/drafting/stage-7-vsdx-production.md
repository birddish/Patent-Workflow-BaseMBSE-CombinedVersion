# 阶段7：VSDX生成与验收

## 图源路径（由阶段6 图源类型决定）

本阶段支持两条路径，由阶段6 的图源类型选择决定：

### 路径A：Mermaid 语义源 → VSDX（默认，适用于 E 域流程图）

- 前置：已确认的阶段6 附图 MD 版本
- 保留 MD 作为 VSDX 的语义源；不得以 VSDX 反向替代或删除 MD
- 内容变更必须先修改 Mermaid 源/阶段5，再重新生成 VSDX

### 路径B：VSDX 直接建模（适用于 M 域结构图、C 域结构式，或用户明确要求）

- 前置：已确认的阶段5 版本（不要求阶段6）
- 直接在 Visio 中绘制结构图、装配图、剖视图、爆炸图或结构式
- 使用 Visio 原生形状手工布置，不经过 Mermaid 自动转换
- 内容变更直接在 VSDX 中修改，同步更新图源版本台账
- 仍须满足本阶段的 Visio 编辑性要求（图层、动态连接器、自定义属性）

### 路径C：混合（同一 VSDX 文件包含两种来源的页面）

- Mermaid 来源页面走路径A 规则
- 直接建模页面走路径B 规则
- VSDX 版本台账标注每页的来源路径

### 通用版本链

无论哪条路径，均须维护：

`实施例版本 → 图源版本（MD 或直接建模记录） → VSDX 文件及页面版本 → DOCX 嵌入版本`

## 前置与输入

- 路径A：核验已确认的阶段6 附图 MD 版本
- 路径B/C：核验已确认的阶段5 版本及附图需求清单

## 必须交付物

| 交付物 | 路径A（Mermaid→VSDX） | 路径B（VSDX直接建模） |
|---|---|---|
| VSDX 文件 | 一个包含全部已确认 MD 图的 VSDX，每幅 MD 图对应一个独立页面 | 一个或多个 VSDX 文件，每幅结构图对应一个独立页面 |
| 对应清单 | MD 图号、VSDX 文件名及页面名称/编号、DOCX 嵌入版本 | 附图编号、VSDX 文件名及页面名称/编号、DOCX 嵌入版本 |
| 生成参数和验收记录 | ✅ | ✅ |
| Word/WPS 插入验证 | ✅ | ✅ |
| 图源核对记录 | MD 节点/边 ↔ 实施例步骤 | 附图 ↔ 实施例结构/装配描述 |

## 生成与验收规则

- 默认仅生成一个 VSDX 文件，并按图号设置其页面名称和顺序；不得为单幅图、单个实施例或局部修改另建 VSDX 文件。仅在用户或专利代理师明确要求拆分时，才可生成多个 VSDX 文件，并在对应清单中记录拆分原因及页面归属。
- 按 A4 正文可用宽度生成；未另行确定页边距时，默认宽度为 158 mm。不得为迁就宽度将主流程图压缩至无法在 Word/WPS 中阅读。
- 路径B（VSDX 直接建模）的结构图应遵循机械制图或化学结构式的一般规范，标注必要的构件编号、装配关系和尺寸参考。

## 流程图布局拓扑规则

流程图必须遵循“单轴主线 + 预留通道”的拓扑，不得以自动层级或均匀网格方式先排节点后连线：

1. **先布主线，再布支线，最后连线**：首先解析Mermaid图结构（节点、边、标签、形状类型）；然后自上而下布置中心轴主流程框；再在中心轴两侧的预留通道及主流程框下方布置分支；最后统一绘制正交连接线、条件标签和汇合横线。
2. **单一中心阅读轴**：每幅图只允许存在一条自上而下贯穿的中心主流程轴；所有分支只能进入中心轴左侧、右侧或主流程框下方的预留通道。中心轴两侧各预留图幅可用宽度的25%作为分支通道，距页边内侧5mm作为跨层跳线通道；不得在中轴左右交替穿插形成多列主流程。
3. **三分支布局**：当同一父步骤分出三条分支时，中心分支继续沿中心轴向下延伸；左右两条分支仅作为临时旁路，处理完毕后须尽快汇合回中心轴。旁路深度建议不超过2层，或横向跨度不超过单侧通道宽度的80%；不得让三条分支同排展开。
4. **子步骤紧随其分支**：带有子步骤的分支，其子步骤必须垂直紧跟在该分支下方，仅与该分支对齐，不得与无关步骤或主流程框对齐。子步骤与父分支的纵向间距不大于相邻主流程框间距的50%。
5. **多路汇合横线**：两条及以上路径汇合时，必须先形成一条水平的“汇合横线”，再由该横线通过一条垂直箭头进入下一主流程框；不得让多条斜向或水平线直接接入框体不同位置。汇合横线位于中心轴正下方，所有汇入分支先水平走线至中心轴后再统一垂直向下。
6. **条件文字位置**：分支条件文字贴在分支刚离开父步骤的第一段连接线上，靠近父步骤框；不得将条件文字放在路径中段、目标框旁或用独立文本框远离分支起点。条件标签文字较长时，可沿连接线自然折行或于图注中补充完整说明；不得因标签排版需要反向要求Mermaid源压缩条件文本。
7. **跨层跳线走外侧**：跨层或长距离跳线一律沿图幅最外侧通道（距页边5mm）走线，回归时从目标流程框顶部的连接点进入；避免横向箭头横穿主流程区域或破坏自上而下的阅读方向。回归目标位于中心主轴时，应先汇入汇合横线再沿主轴向下。
8. **流程框宽高原则**：流程框宽度以文字可读为准，最小宽度20mm，最大宽度100mm；允许自然折为两行或三行；字号不小于9pt；同一图中同类型框体尺寸一致。宁可增加框体高度，也不得使用单条超宽框体并压缩字体。

## Mermaid到Visio的转换流程

阶段7不直接复用Mermaid自动布局的坐标，而是读取其图结构后按中心轴规则重新生成VSDX。转换流程如下：

1. **解析结构**：读取Mermaid源中的节点、边、边标签和形状类型。
2. **映射形状**：将Mermaid形状按下列约定映射为Visio“基本流程图”标准形状：

   | Mermaid 形状 | Visio 基本流程图形状 |
   |---|---|
   | `([开始])`、`([结束])` | 终结符 |
   | `[处理]` | 过程 |
   | `{判断}` | 判定 |
   | `[/数据/]` | 数据 |
   | `[文档]` | 文档 |
   | `{{预定义过程}}` | 预定义过程 |

3. **识别主线与分支**：根据流程语义识别中心轴主流程节点、左侧/右侧/下方分支、临时旁路、多路汇合点和跨层跳线。
4. **布置中心轴**：将主流程节点自上而下排列在页面中心轴上，保持阶段5步骤顺序。
5. **布置分支**：在预留通道中放置分支节点和临时旁路；旁路处理完毕后导向汇合点。
6. **绘制正交连接线**：先连接中心轴主流程，再连接分支与旁路，最后绘制跨层跳线。所有连接线必须为水平或垂直的直角线。
7. **放置条件标签与汇合横线**：条件标签贴在分支离开父步骤的第一段线上；多路汇合处先形成水平汇合横线，再垂直进入下一主流程框。
8. **应用样式与图层**：按Visio模板设置形状样式，将图元分配到对应图层，写入自定义属性（`SourceNodeID`、`SourceStep`、`FigureVersion`）。

## Visio文件编辑性要求

为便于专利代理师在Visio中二次编辑，生成的VSDX应满足：

- **图层结构**：至少包含以下图层：
  - `流程框`
  - `判定框`
  - `连接线`
  - `条件标签`
  - `标题图号`
  - `辅助参考线`
  - `预留通道边界`（可隐藏）
- **动态连接器**：所有框间关系使用Visio动态连接器，端点必须吸附到形状连接点，保留随节点移动自动重布线能力。
- **独立可编辑**：节点、连接线、标签保持独立，不整体Group；确需组合时，应在验收记录中说明理由。
- **自定义属性**：每个承载流程语义的形状保留：
  - `SourceNodeID`：对应源Mermaid节点标识
  - `SourceStep`：对应阶段5实施例步骤编号（如S2-1）
  - `FigureVersion`：图源版本号
- **样式一致**：基于统一模板或样式参数，同一图中同类型形状的大小、字体、填充、边框一致。模板规范见 `references/templates/visio-template-spec.md`；如未提供模板文件，按该规范中的默认参数生成。

## 输出目标与导出

根据VSDX后续用途选择导出方式：

| 用途 | 推荐格式 | 关键要求 |
|---|---|---|
| Word/WPS嵌入 | VSDX对象或EMF | 矢量可缩放，文字可选中 |
| PDF归档 | 矢量PDF | 检查字体嵌入、线条完整性 |
| 专利电子申请 | 黑白TIFF/PDF，≥300dpi | 无透明、无渐变、灰度或黑白 |
| 打印 | PDF或纸质样张 | 最小线宽0.25pt，9pt以上字号清晰可辨 |

导出前须再次检查图号、标题、节点文本、分支条件、箭头和连接线在目标格式中无重影、溢出或重叠。

## 反向编辑策略

### 路径A（Mermaid→VSDX）

- **版式微调**：允许在 Visio 中直接调整节点位置、间距、连线拐点，无需回写 Mermaid；但应在阶段7 确认单中记录显著调整。
- **内容修改**：节点增删、文本变更、逻辑关系变更、分支增减必须先修改 Mermaid 源/阶段5，再重新生成 VSDX。Visio 中的内容变更不得作为最终来源。
- **版本同步**：若 Visio 中发生内容变更，必须同步更新 Mermaid 源，并在 MD—VSDX—DOCX 版本对应清单中标注差异。

### 路径B（VSDX 直接建模）

- **内容修改**：直接在 VSDX 中修改结构图；内容变更记录在图源版本台账中
- **版本同步**：VSDX 更新后同步更新"实施例版本—图源版本—VSDX 版本—DOCX 嵌入版本"链
- **阶段5 联动**：若结构变更影响实施例描述（如构件增删、装配关系变化），须同步更新阶段5

### 通用规则

- 依据实际字体度量和节点文字长度计算节点宽度、字体大小和分层数量，不以手工插入换行符伪造两行效果
- 在 A4 可读性允许时，使同图节点尺寸一致、节点文本不超过三行
- 使节点文本位于节点形状内，条件标签可见，连线不遮挡节点或文本，节点和标签不重叠
- 所有承载流程功能或语义的节点，均应使用Visio“基本流程图”模具中的标准形状：按语义选用过程、判定、开始/结束、数据、文档等形状；不得以普通矩形、圆角矩形、文本框或其他非“基本流程图”形状代替。仅图号/标题等辅助文字可使用简单文本框；确无对应基本流程图形状且经专利代理师确认时，才可使用其他基础二维形状，并在验收记录中说明必要性。
- 使用Word/WPS可识别的基本流程图形状、辅助文本框和原生Visio一维直角连接线生成VSDX。每一条框间关系必须以直角（正交）连接线实现：线段仅可水平或垂直，转折处为90°；不得使用斜线、曲线或自由曲线连接器。连接线两端应分别吸附（glue）至起止节点的连接点，并保留其随节点移动而自动重布线的连接关系；不得用细长矩形、普通二维线状形状、节点边框延伸或其他形状模拟连线。箭头应设置在连接线的端点，连接线不得承载节点正文；分支条件文字贴在分支刚离开父步骤的第一段连接线上，不得以独立文本框置于路径中段或目标框旁。
- 检查VSDX OOXML包结构完整、文件可正常打开及页面和图元完整性，并检查图号/标题、MD步骤/分支数量及文本对应、文本溢出、重叠、裁切、箭头方向和A4缩放后的可读性；不得仅以文件可打开作为通过依据。逐个核验功能节点的形状类别及任何例外的批准记录；逐条核验框间关系：连接线应为一维图元（`OneD=1`），并具有指向起止节点连接点的连接记录（`Connects`），且各线段均为水平或垂直、转折处为90°；如仅在视觉上接触节点而未建立连接关系，或存在斜线、曲线，判定为不通过。
- 实际打开该VSDX并逐页在目标Word或WPS文档中验证，确认步骤文字、分支条件、箭头和框线均可见且没有重影、溢出或重叠。若不通过，修改MD图源或VSDX生成规则后重新生成并重新检查。
- VSDX更新后，检查申请DOCX所用页面是否仍为旧版；如是，重新插入或导出最新页面并记录DOCX嵌入版本。保留MD源和单一VSDX并存；若VSDX需修改，先修改MD并重新生成，再复核对应关系。

## 拓扑专项验收清单

除OOXML结构和形状检查外，每页流程图必须通过下列拓扑检查：

- [ ] 仅存在一条自上而下贯穿的中心阅读轴；
- [ ] 所有分支均位于中心轴左侧、右侧或主流程框下方的预留通道；
- [ ] 三分支时中心分支继续向下，左右分支为临时旁路且旁路深度/跨度符合限制；
- [ ] 子步骤紧跟其所属分支下方，不与无关步骤或主流程框对齐；
- [ ] 多路汇合先形成水平汇合横线，再垂直进入下一主流程框；
- [ ] 条件文字贴在分支离开父步骤的第一段线上，无路径中段或目标框旁标注；
- [ ] 跨层跳线沿图幅最外侧走线，回归时从目标框顶部进入；
- [ ] 无超宽框体、压缩字体或文本溢出；
- [ ] 每个Visio流程节点均可在源Mermaid图中找到对应 `SourceNodeID`；
- [ ] 源Mermaid图中的每个功能节点均已落入Visio图中，无遗漏；
- [ ] 图层结构、动态连接器、自定义属性符合Visio文件编辑性要求；
- [ ] 导出目标格式（Word/PDF/电子申请/打印）已验证无重影、溢出或重叠。

## 确认门

登记阶段7 版本、VSDX 验收记录、图源—VSDX—DOCX 版本对应清单及 Word/WPS 验证结果。确认单中至少包括：

- VSDX 可用于申请文件的版式确认
- 图源路径（A/B/C）及对应验收项
- 路径A：拓扑专项验收清单全部通过或已记录偏差及理由
- 路径B：结构图标注完整性、装配关系清晰性验收
- 图层结构、动态连接器、自定义属性已按 Visio 文件编辑性要求设置
- 导出的目标格式已验证通过
- DOCX 嵌入版本与最新 VSDX 页面一致
- 输出目标与导出格式已确认；
- 反向编辑策略已告知专利代理师，显著版式调整或内容变更已记录。

由专利代理师明确确认上述事项后，方可进入最终组卷。
