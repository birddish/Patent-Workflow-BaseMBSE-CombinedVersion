# 确认门与版本回退

## 阶段确认流程

1. 每一阶段在本次对话首次处理时，先创建或核验对应阶段文件夹；仅在这是新的独立对话时确定下一会话序号。登记输入文件名、版本或修改日期、前序确认记录和本阶段当前输出文件。

2. 每一阶段结束时，直接更新本次对话的"阶段确认单"，载明：
   - 阶段编号
   - 输入版本
   - 输出文件路径
   - 待确认问题
   - 前序依赖
   - 下一阶段
   - 明确请求专利代理师确认

   不得在同一对话中为确认单反复另存版本。

3. **未获得专利代理师对当前版本的明确确认，不得生成下游正式交付物、确认后续阶段或进入最终组卷。** 提出修改、补充材料或一般意见不构成确认。

4. 因业务安排需要并行草拟时，只能生成明确标记为"预审草案"的非正式文件，不得形成阶段确认、不得作为阶段4至阶段8或最终 DOCX 的输入。

## 版本回退规则

前序已确认文件变更时：
- 标记依赖该文件的下游输出为"待复核"
- 回到最早受影响阶段，完成更新并重新取得确认后方可继续

具体回退触发条件：

| 变更类型 | 回退阶段 | 说明 |
|----------|----------|------|
| 阶段3 PU/PST/CTX、特征取舍、保护层级、必要关系或主创新点变化 | 回退阶段1 | 按四层映射账本回写，影响IU或对象边界时同步回退阶段2 |
| 题名、术语、编号、技术关系或步骤逻辑变更 | 至少复核阶段4、阶段5及最终组卷 | 引用一致性复核 |
| 新增技术内容、来源缺失或主技术问题变化 | 回退阶段1 | 影响检索布局时同步阶段2 |
| 权利要求层级、保护主题或特征组合需调整 | 回退阶段3 | — |
| 背景、实施方式或技术效果支撑不足 | 回退阶段4或阶段5 | — |

## 缺失前置的调用

直接调用阶段2至阶段5时，若缺少已确认的前序输出或其版本失效，只输出缺失/失效清单和待确认问题，不生成该阶段的正式交付物。

阶段6、阶段7仅在用户明确要求时适用其各自前置核验。阶段8可在阶段5后作为默认终审，也可独立启动；阶段6、阶段7未启动时登记为"未启动"，既有附图未提供时登记为"未提供"，不得以此阻断文字审计与说明书补强。

## 阶段3 母版阶段内确认门

阶段3另设母版阶段内确认门：该确认只允许进入母版分配、依赖图审计和可选提交策略轮次，不构成阶段3结束确认，也不允许提前进入阶段4。

仅在专利代理师明确确认母版文本、PU/PST、核心技术问题、独权必要特征和回退层级后进入第二轮。未获确认时停止，不生成正式提交候选版，也不进入阶段4。未设置`target_claim_count`时不得启动数字压缩。

## 阶段2 状态区分

阶段2 必须在台账中明确区分以下状态，不得混用：

1. **检索策略**：创新单元、关键词、分类和拟用数据库已经设计
2. **静态检索式验证**：仅完成逻辑、语法、术语或预估命中验证，未形成实际检索证据
3. **实际检索执行**：已保留可复现的查询、日期、数据库、结果范围和筛选记录
4. **证据化比对结论**：已对核心文献完成全文定位，并形成可复核的特征比对和保护布局建议

仅处于前两种状态时，阶段2 未完成。经明确业务授权可以生成标注为"预审草案"的权利要求构思，但不得形成阶段3 正式权利要求、阶段3 确认单或阶段4 至阶段8 的正式输入。

## 阶段8 确认

审计终审通过后，形成"申请文件审计确认单"，至少记载：

- 版本台账
- 母本—最终件比对表
- 主创新点锚定卡
- 事实来源轴、撰写采用轴及PU准入状态
- P0/P1/P2/P3 问题关闭情况
- 遗留风险
- 阶段6/阶段7 是否未启动
- 是否锁定权利要求
- 可提交性结论
- 代理师确认栏
