# phase_02 事实核实

按请求人实际主张顺序逐理由核实；二次或后续答辩必须逐项覆盖新增理由、新增证据和新增权项主张。每项记录请求人原文、权项及版本、特征、证据直接原文、页码/段落/图号/表号、公开日来源、原文与译文对应关系及冲突。

支持、新颖性、创造性和其他理由分开。新颖性对每份证据单独逐特征比对，不能跨证据拼接。创造性另行记录最接近证据、区别特征、组合顺序、动机、接口、输入输出、行为连续性、技术问题和效果。公知常识、技术偏见、常规试验、公开日、译文和程序事实均需证据；对照表每格须填写原文、定位、明确公开、未见公开、无法确认或差异说明。

模板法条、指南段号、修改规则和期限不是预核验结论。最终意见前按案件时点核对当前有效专利法、2023 年专利法实施细则、当前专利审查指南（含 2025 年修改决定及施行时间）、本案程序通知、送达和期限依据。CNIPA 官方页面只是核对入口。缺少可定位文本、核验日期和来源即为 pending_review 或 blocked。

创造性须针对权利要求限定的整体技术方案，不能以未公开特征数量或孤立差异替代；贡献特征必须与技术问题和技术效果建立证据可查的对应。

官方入口仅作定位。B（case_json_only）不得访问该 URL；法规/通知不在 case.json 时返回 blocked/need_reimport，待用户明选 C 导入后再分析。
