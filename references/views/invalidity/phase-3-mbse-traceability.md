# phase_03 MBSE 追溯与逐理由分析

对每个理由、权项和证据建立 R/F/S/B/E 链：R 是权项限定和答辩需求，F 是功能，S 是结构/步骤/关系，B 是输入输出、时序和行为，E 分开记录直接证据与技术效果。节点带特征、理由、证据、来源片段、status、input_revision、dependency_ids、rule_version 和待核实问题。

独权 N.1 为主题名称、N.2 起为技术特征；从权 N.1 为首个附加特征。产品与方法分别分析结构/步骤及其关系。

新颖性固定权项版本，对每份证据逐项列出全部限定和原文定位，判断单份覆盖、未见公开或待核实。创造性不得沿用新颖性表格，另记录最接近证据、区别特征、组合顺序和动机、接口与行为连续性、技术效果、公知常识、技术偏见及相反启示。创造性评价针对整体技术方案，贡献特征、技术问题和技术效果须相互对应。工程断点只能是技术分析，不自动推出法律结论。
