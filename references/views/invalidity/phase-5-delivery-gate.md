# phase_05 交付前核对

必须按案件时点核对当前有效专利法、2023 年专利法实施细则、当前专利审查指南、2025 年修改决定及施行时间、本案程序通知、送达和期限。模板引文不等于核验完成。不能以未公开特征数量、孤立差异或工程断点替代创造性分析。

对外稿不得泄露内部 ID、status、revision、JSON Pointer、source_path 或规则名。权利要求修改和最终请求范围须用户明文确认。任一缺口只能标为 blocked、pending_review 或 candidate，不得称定稿、已完成或可直接提交。只输出 JSON 来源的 Markdown/纯文本，不生成 DOCX/PDF。
