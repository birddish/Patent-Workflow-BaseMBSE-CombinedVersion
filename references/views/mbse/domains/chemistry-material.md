# 化学/材料领域 MBSE 建模规则

适用于组合物、材料、配方、催化剂、制备方法、涂层、电池、聚合物、晶型及过程化学。

---

## disclosure 模式（交底书建模）

### 提取重点

- **R**：收率、纯度、稳定性、活性、选择性、强度、电导率、耐热性、生物相容性、环境/工艺约束
- **F**：反应、催化、分散、交联、掺杂、涂覆、固化、分离、吸附、释放、稳定、传导、增强
- **S**：组分、配比、分子结构、物相、粒径、层、基底、添加剂、催化剂、溶剂、装置
- **B**：加料顺序、反应顺序、温度/时间/pH/压力曲线、混合、固化、煅烧、洗涤、干燥
- **E**：可测量的收率、纯度、活性、稳定性或性能效果

### 防护规则

- 除非交底书明确要求保护该范围，不得从单一实施例推演范围
- 不得在无依据的情况下推测协同作用、结晶度或催化途径等机制
- 将组成节点（S）与工艺行为节点（B）分开
- 对比例是证据；建模效果时不得忽略对比例

## document 模式（专利文本建模）

### 提取要点

- **R**：收率、纯度、稳定性、活性、选择性、强度、电导率、耐热性、生物相容性、环境/工艺约束
- **F**：反应、催化、分散、交联、掺杂、涂覆、固化、分离、吸附、释放、稳定、传导、增强
- **S**：组分、配比、分子结构、物相、粒径、层、基底、添加剂、催化剂、溶剂、装置
- **B**：加料顺序、反应顺序、温度/时间/pH/压力曲线、混合、固化、煅烧、洗涤、干燥
- **E**：已公开的范围、配比、条件、粒径、分子量、晶体参数、性能指标相关效果

### 工艺/组成卡片

| 字段 | 必填内容 |
|------|---------|
| 组分 | 名称、作用、配比/范围 |
| 工艺顺序 | 顺序与处理方式 |
| 条件 | 温度、时间、pH、压力、气氛、溶剂 |
| 生成结构 | 物相、形貌、层、组成、晶型 |
| 实测效果 | 性能与指标 |
| 证据 | 权利要求/段落/实施例及 D/I/Q/X |

### 防护规则

- 除非文本明确要求保护该范围，不得从单一实施例推演范围
- 不得在无依据的情况下推测协同作用、结晶度或催化途径等机制
- 将组成节点与工艺行为节点分开
- 对比例是证据；建模效果时不得忽略对比例
- 必须区分组分/结构节点、工艺行为节点、条件约束节点和性能效果

### 权利要求桥接检查

化学/材料领域的 `ClaimSpan/CF/REL` 应同时保留组分或结构、配比/范围、工艺顺序、条件约束、生成结构和性能效果，并回指权利要求、说明书段落、实施例或对比例。单一实施例、相似组成或未经验证的机理不得替代完整组合支持；对比例和实验锚点应在 `SupportLink` 中明确记录。
