# 机械/结构领域 MBSE 建模规则

适用于机械、机电、传动、导向、装配、执行器、连杆、夹具、工装及运动机构。

---

## disclosure 模式（交底书建模）

### 提取重点

- **R**：力、运动、定位、精度、可靠性、磨损、装配、空间、载荷、密封、热或安全要求
- **F**：支撑、驱动、导向、限位、夹紧、传递、旋转、平移、密封、缓冲、检测、调节
- **S**：零件、组件、连接件、铰链、导轨、齿轮、带、链、轴承、弹簧、电机、气缸、传感器
- **B**：运动顺序、力传递路径、接合/脱开、位置变化、调节路径、失效/极限状态
- **E**：可测量的力学、运动学、精度或可靠性效果

### 机械关系记录卡

对每一条关键传动、转向或导向路线填写：

| 字段 | 记录内容 |
|------|---------|
| 结构边界 | 分析的部件、轨道或机架范围 |
| 几何基准 | 曲率中心、行进方向、中心线、内/外侧定义 |
| 主动源 | 电机、链轮、皮带轮、气缸等 |
| 作用界面 | 啮合、摩擦接触、销轴连接、齿条啮合等 |
| 直接受力件 | 在作用界面实际接收驱动力的部件 |
| 非直接受力件 | 经相邻部件/连接关系获得运动的部件 |
| 传递关系 | 拉力、压力、剪力、摩擦力、反力；不明则标 Q |
| 约束与导向 | 轨道、滚轮、铰接、限位、支撑接触 |
| 可观察运动 | 平移、转动、随轨转弯、相对摆动 |
| 证据与标签 | 段落/附图及 D/I/N/G/Q/X |

### 防护规则

- 不要仅依据"链条""皮带""齿轮"等名称，直接判定其全部传力方向或所有非直接受力件的状态
- 不得仅凭"链""齿轮""带"等名称推断所有力的方向
- 不得将附图外观视为明确公开，除非附图无歧义地显示了该关系
- 不得推测尺寸、公差、材料、载荷或性能，除非已公开或由明确文本限定
- "内圆弧/外圆弧"必须说明相对哪个曲率中心和行进路径；不能把机架路径、轨道路径与传动单元自身的形状混为一谈
- 齿轮/链条的接口匹配可作为 D 结构关系或 I 工程约束；除非文件或可复核分析给出依据，不得升级为"单元必然不能加长"或"必然堆积"
- 除非已公开或已确认，否则不得断言数值化或绝对的工程效果

## document 模式（专利文本建模）

### 五层提取重点

- **R**：力、运动、定位、精度、可靠性、磨损、装配、空间、载荷、密封、热或安全要求
- **F**：支撑、驱动、导向、限位、夹紧、传递、旋转、平移、密封、缓冲、检测、调节
- **S**：零件、组件、连接件、铰链、导轨、齿轮、带、链、轴承、弹簧、电机、气缸、传感器
- **B**：运动顺序、力传递路径、接合/脱开、位置变化、调节路径、失效/极限状态
- **E**：已公开的力学、运动学、精度或可靠性效果

### 机械关系卡片（document 模式）

对每条关键路径记录：

| 字段 | 必填内容 |
|------|---------|
| 边界 | 所分析的零件/组件/机架 |
| 几何基准 | 中心、轴线、方向、内侧/外侧、基准 |
| 主动源 | 电机、气缸、齿轮、链、带、人力 |
| 接口 | 接触、啮合、铰接、滑动副、导向、紧固件 |
| 直接受驱元件 | 在接口处受力/运动的元件 |
| 间接受驱元件 | 通过另一结构被带动的元件 |
| 力/运动类型 | 拉伸、压缩、扭矩、摩擦、反力、旋转、平移 |
| 约束 | 导轨、限位、支撑、轴承、导向、止挡 |
| 证据 | 权利要求/段落/附图及 D/I/Q/X |

### 防护规则

- 不得仅凭"链""齿轮""带"等名称推断所有力的方向
- 不得将附图外观视为明确公开，除非附图无歧义地显示了该关系
- 不得推测尺寸、公差、材料、载荷或性能，除非已公开或由明确文本限定
- 是否将"图中看起来如此"误写成"文件明确公开"
- 是否把尺寸、受力或效果推断写成绝对结论

### 输出前核验

1. 每一关键箭头是否标明连接、接触、运动或力的类别？
2. 每一结论性节点是否有来源和 D/I/Q/X 标签？
3. 是否将两份文件的结构关系混合到了同一张图？
4. 是否把"图中看起来如此"误写成"文件明确公开"？
5. 是否把尺寸、受力或效果推断写成绝对结论？

### 权利要求桥接检查

机械领域的 `ClaimSpan/CF/REL` 应明确记录几何基准、作用界面、受力或运动关系、顺序和参数，并回指对应附图或说明书位置。特征进入完整权利要求组合前，必须通过 `SupportLink` 的组合语境和人工复核；不得只因零件名称相似而认定结构或力路对应。
