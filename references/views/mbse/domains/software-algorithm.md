# 软件/算法领域 MBSE 建模规则

适用于软件、AI/ML、数据库、访问控制、推荐、搜索、文档处理、工作流引擎及计算机实现的方法。

---

## disclosure 模式（交底书建模）

### 提取重点

- **R**：时延、准确率、可扩展性、一致性、安全性、隐私性、资源消耗、容错性
- **F**：解析、检索、分类、匹配、训练、推理、验证、转换、聚合、授权、调度、生成
- **S**：模块、服务、模型、索引、表、缓存、队列、API、处理器、存储介质、特征向量、规则引擎
- **B**：算法流程、请求/响应时序、状态机、训练循环、推理路径、更新路径、异常处理
- **E**：可测量的性能、精度、效率或资源消耗效果

### 防护规则

- 不得将商业目标在缺少技术机制的情况下当作技术需求
- 不得将"AI""LLM""智能"或"自动"视为完整结构——必须有具体的模型类型、输入输出和推理流程
- 不得凭空编造提示词、训练数据、模型架构、阈值或评估指标
- 算法流程必须记录输入、转换、输出、实现模块、触发条件和异常路径

## document 模式（专利文本建模）

### 提取要点

- **R**：时延、准确率、可扩展性、一致性、安全性、隐私性、资源消耗、容错性、技术过程的自动化
- **F**：解析、检索、分类、匹配、训练、推理、验证、转换、聚合、授权、调度、生成
- **S**：模块、服务、模型、索引、表、缓存、队列、API、处理器、存储介质、特征向量、规则引擎
- **B**：算法流程、请求/响应时序、状态机、训练循环、推理路径、更新路径、异常处理
- **E**：已公开的阈值、公式、排序规则、字段模式、向量维度、时间限制、一致性规则相关效果

### 算法记录卡片

| 字段 | 必填内容 |
|------|---------|
| 输入 | 数据字段、文档块、事件、请求、传感器记录 |
| 转换 | 规则、模型、公式、匹配逻辑、流水线 |
| 输出 | 标签、分数、向量、决策、生成内容、指令 |
| 分配结构 | 模块/模型/数据库/API |
| 行为 | 触发条件与执行顺序 |
| 证据 | 权利要求/段落/附图及 D/I/Q/X |

### 防护规则

- 不得将商业目标在缺少技术机制的情况下当作技术需求
- 不得将"AI""LLM""智能"或"自动"视为完整结构
- 不得凭空编造提示词、训练数据、模型架构、阈值或评估指标
- 不得把商业流程直接建模为技术机制

### 权利要求桥接检查

软件/算法特征进入 `ClaimSpan/CF/REL` 时，应保留输入字段、转换规则或模型、输出、执行模块、触发条件、状态和异常路径，并回指具体段落、权利要求或附图。不得以“AI”“LLM”“自动”或流程目标替代可核验的技术关系，也不得以生成文本或评价分数直接证明技术效果或法律结论。
