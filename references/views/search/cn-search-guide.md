# 中国专利核验与六法域衔接指南

## 默认范围

- 每个案件必须覆盖中国(CN)、美国(US)、日本(JP)、韩国(KR)、欧洲专利(EP)和 PCT 国际申请(WO)六法域。本指南负责中国官方核验及与全球检索的衔接，其他法域的具体方法见 [search-guide.md](search-guide.md)。六法域是必查范围，不等于默认从六次独立法域检索开始。
- 默认先形成中文、英文、日文、韩文、法文和德文关键词块，在全球数据库中执行不限定法域的统一检索。中文核心技术词同时补充各语种同义词、缩写、译名和原文表达。
- 全球检索覆盖中国发明与实用新型公开文献；产品外观可能构成风险时，将外观设计纳入相应 FTO 权利判断地域。六法域文献覆盖范围与 FTO 权利判断地域必须分开记录。
- 默认最终附件为经书目核验的公开号/专利号清单和报告，不要求下载、保存或附送本地 PDF。进入核心候选集并用于实质技术结论的文献，必须通过 MCP 或可信全文渠道读取并核对权利要求、说明书或附图；MCP 返回的内容无需另存为 PDF。
- 先在 `global_core_patent_database` 等全球数据库中进行六语跨法域统一检索，再使用 CNIPA 专利检索及分析系统抽查中国覆盖、核验号码；需要法律状态时，通过中国及多国专利审查信息查询核验案件进展。CNIPA 不作为默认起手的单独法域检索。系统界面、字段和可导出格式以当前页面为准。
- 仅在用户明确要求缩减范围并记录理由、未查范围和结论影响时，方可省略任一必查法域。

## 检索式构建

1. 将技术方案拆为 2–4 个检索块：技术领域、核心结构/步骤、功能或效果、可选材料/参数。
2. 每块列出中文、英文、日文、韩文、法文和德文的同义词、简称、全称、行业常用表达、上位词与下位词；不要把全部要件一次性相与。机器翻译词须用近似文献原文、同义词或分类验证。
3. 先用名称、摘要和权利要求字段试探；噪声过高时收窄至权利要求或增加 IPC，漏检时放宽字段或删除限制块。
4. 从跨法域近似文献提取 IPC/CPC，并将分类加入全球统一式；需要深入日本文献时补充 FI/F-term。不要把 FI/F-term 当作全球数据库或中国数据库的默认分类字段。
5. 保存每条全球查询的原样文本、六语关键词、字段、时间、命中数和导出文件名。若结果量超过一次性完整、稳定提取上限，先分页或分批；仍不能完整取得时才考虑按法域拆分，并记录工具上限、尝试方式和失败结果。不得仅因数据库界面或操作习惯预先按法域拆分。

## 六法域覆盖核验职责

| 覆盖法域 | 全球主检索与官方核验渠道 | 全球统一式语言与分类 | 最低完成记录 |
|----------|--------------------------|------------------------|--------------|
| CN | Global Core Patent Database；CNIPA 核验 | 中英日韩法德；IPC/CPC | 全球式、总命中数、日期、CN 结果分布/抽查及号码清单 |
| US | Global Core Patent Database；USPTO 核验 | 同左 | 全球式及 US 结果分布/抽查 |
| JP | Global Core Patent Database；J-PlatPat 核验 | 同左；必要时 FI/F-term | 全球式及 JP 结果分布/抽查 |
| KR | Global Core Patent Database；KIPRIS 核验 | 同左 | 全球式及 KR 结果分布/抽查 |
| EP | Global Core Patent Database；Espacenet/European Patent Register 核验 | 同左 | 全球式及 EP 结果分布/抽查 |
| WO/PCT | Global Core Patent Database；PATENTSCOPE 核验 | 同左；必要时 CLIR | 全球式及 WO 结果分布/抽查 |

一次不限定法域的全球查询是默认主检索方式。必须将其结果按公开国别/机构代码映射到六法域覆盖表，并对异常空白或明显偏少的法域用官方或可信渠道抽查。只有结果量超过一次性稳定提取上限且分页/分批仍失败时，才允许改用按法域拆分式；拆分不是六法域覆盖核验的默认要求。

## 号码核验、CNIPA 与 FTO

- 对每一件进入报告的中国专利，记录公开号/专利号、名称、申请人、申请日、公开日或授权公告日、核验渠道与日期。
- 候选号码只需先在官方或可信数据库中完成书目解析；进入核心候选集后，必须通过 MCP 或可信全文渠道进一步核对权利要求、说明书或附图，但不要求取得或保存本地 PDF。
- 对拟用于实质性 FTO 判断的核心权利，必须进一步在中国及多国专利审查信息查询、等效 CNIPA 官方渠道或可信数据库核验：案件类型、当前法律状态、当前有效的权利要求文本、年费/终止或届满相关信息，以及审查中申请的公开情况。未进行该核验时只交付风险线索号码，不作实质 FTO 结论。
- 仅以检索页面摘要、搜索引擎片段或第三方聚合站的状态信息，不得作出“有效”“失效”“不存在侵权风险”等结论。
- 无效资料检索应区分公开日、申请日和优先权日，并以用户确定的基准日判断可作为现有技术的时间条件。

## 用户协作任务

当需要核验中国覆盖但无法直接访问 CNIPA，或已经满足法域拆分触发条件而需要用户协作时，向用户给出以下内容：

1. 待粘贴的全球六语检索式；只有已满足拆分触发条件时才提供中文法域拆分式，并附触发记录；
2. 应选择的字段、文献类型、时间范围和 IPC 限制；
3. 需要返回的命中数以及包含公开号/专利号的结果清单、CSV/Excel；PDF 和审查信息截图/导出均为可选。核心文献由助手优先通过 MCP 或可信全文渠道读取权利要求、说明书或附图，不要求用户另存 PDF；
4. 对已知基准文献的命中验证结果。

其他任一必查法域需要官方抽查时，也按同一结构给出对应官方渠道、核验步骤和应返回的号码清单；官方核验不改变全球统一检索优先级。只有满足提取上限条件时才给出法域拆分检索式。将带回资料标为“用户提供”；号码经书目解析后即可作为号级线索列入候选清单。拟作为核心文献时，再由助手通过 MCP 或可信全文渠道核对具体技术特征；只有这些渠道无法读取时才请求用户补充文本或 PDF，且不要求长期本地保存。在结果返回前将该法域标为“待核验”，不得宣告六法域覆盖完成。
