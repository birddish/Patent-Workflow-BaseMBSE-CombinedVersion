# 案件准入与交付就绪性门

## 1. 目的

将“能否开始技术分析”、“能否形成可靠答复”和“能否正式提交”分为三个门。材料不齐时允许形成条件性分析，但不得隐藏边界或把工作稿标记为可提交。

## 2. 案件准入表

| 类别 | 必查项 | 状态 | 缺失时处理 |
|---|---|---|---|
| 程序文件 | 审查意见通知书/驳回决定全文、发文日、答复期限 | D/Q | 缺失则提交状态 blocked |
| 申请文件 | 原权利要求、说明书、附图、摘要、历次修改文本 | D/Q | 缺失影响修改支持或版本时，内容状态不得 pass |
| 引证文件 | 审查员引用的全文、附图、书目信息、公开日 | D/Q | 仅有摘要/节选时使用“已提供材料未见”，不得使用“全文无记载” |
| 权利要求版本 | 当前文本、替代关系、修改支持依据 | D/Q | 建立版本链；不确定时不定稿 |
| 提交信息 | 申请号、申请人、发明名称、代理信息、签章/替换页要求 | D/Q | 内容稿可继续，提交状态 blocked |
| 客户决策 | 保护范围取舍、删除/分案、事实确认 | D/Q | 列为客户确认项，不擅自定为最终方案 |

## 3. 对比文件时间资格门

每篇文献分别记录新颖性和创造性证据资格，不用单一的“对比文件”标签替代法律时间角色。

| 情形 | 新颖性用途 | 创造性用途 |
|---|---|---|
| 基准日前已公开并已核验 | 可用 | 可用 |
| 基准日后公开的在先申请，抵触申请条件已核验 | 仅按法定范围用于新颖性 | 不得用于创造性组合 |
| 公开日、优先权或主体条件未核验 | 条件性分析，标记 Q | 条件性分析，标记 Q |
| 基准日后首次公开且不属于可用的抵触申请 | 不可用 | 不可用 |

## 4. 三个门的结论

### 门 A：可建模

至少具有审查意见的可读内容、当前申请文件与引证文件的可读内容。否则停留在材料清单。

### 门 B：内容可靠

核心事实、时间资格、权利要求版本与修改支持不存在影响结论的 Q；问题覆盖率为 100%；新版权利要求已重算 NB/IS。

### 门 C：可提交

门 B 通过，且期限、申请人/代理信息、替换页/签章、客户范围取舍等形式与授权事项均已确认。

## 5. 必交结论格式

```yaml
readiness:
  content_status: pass | conditional | fail
  submission_status: ready | blocked
  blockers: []
  client_confirmation_required: []
```

`content_status=pass` 与 `submission_status=ready` 是两个独立结论；只有两者同时满足时才能对用户表述为“可直接提交”。
