# 机械/结构域论证模式

## 使用边界与答审链条

本文件供 答审/复审视图 的 mechanical mode 在阶段三和阶段四按需读取。机械论证模式是选择器，不是固定话术或法律结论。只有在阶段二完成事实核实、阶段三形成可重放 CombinationPath 后，才可选择模式；结构关系、工作条件或证据不足时标记 Q 或 blocked。

机械案件统一沿以下链条工作：

~~~text
审查员主张
  → 对比文件原文/附图/实施例
  → 当前 ClaimVersion 的 R/F/S/B/E 节点
  → 区别构件、关系、行为或参数与技术效果
  → CombinationPath（D0、Dk、操作、Ω、中间状态）
  → 空间、接口、接触、受力、运动、状态和效果闭合
  → TeachingRecord 与 EffectEvidenceCard
  → ArgumentOnly 或 AmendmentBased
  → 新权利要求版本与重新评价
  → DecisionTrail
~~~

机械最小技术链：

~~~text
R 技术问题
  → F 所需功能
  → S/REL 构件及结构关系
  → B/STATE 受力、运动和状态转换
  → E 技术作用或效果
~~~

节点覆盖不等于追溯等价。零件名称同时出现只能证明节点可能存在，还必须检查连接、位置、配合、接触、受力、运动、状态和效果是否保持。工程上能够重新加工、安装或替换，不等于现有技术给出了到达路径。

## 模式选择矩阵

| pattern_id | 主要断点 | 主要 MBSE 对象 | 不得单独推出 |
|---|---|---|---|
| ME-01 | 多个区别特征是否构成一体化机械配合 | S/REL、B/STATE、E | 零件并列即有协同效果 |
| ME-02 | 对比文件组合、替换或重装是否兼容 | S/REL、接口、CombinationPath | 结构不相同即必然没有动机 |
| ME-03 | 动力源、受力和运动路径是否保持 | B/STATE、力流和运动流 | 受力术语不同即自动具备创造性 |
| ME-04 | 尺寸、节距、间隙和接口是否共同可满足 | S/REL、参数和装配约束 | 附图比例可证明确定尺寸 |
| ME-05 | 传统替代是否保持原工作原理和效果 | CombinationPath、TeachingRecord | 存在替代件即存在结合启示 |
| ME-06 | 结构需求与驱动/控制选择是否存在因果关系 | R→F→S/B、TeachingRecord | 设计先后顺序本身就是技术启示 |

## 各模式共用的记录合同

每个模式至少填写：

| 字段 | 要求 |
|---|---|
| pattern_id、claim_version_id、issue_id | 绑定当前权利要求和审查员争点 |
| applicability、non_applicability | 写明命中前提和不适用边界 |
| mbse_layers | 标明 R/F/S/REL/B/STATE/E 对象 |
| required_facts | 构件、关系、位置、配合、受力、运动、状态、参数和证据位置 |
| D0、Dk、feature_transfer | 写明每篇文件的技术作用和被提取内容 |
| operation_sequence | 加入、替换、重连、重排、调整及中间状态 |
| Ω | 允许的结构、尺寸、装配或驱动适配；没有来源时标 Q |
| mechanical_constraints | 空间、装配、接触、支撑、啮合、尺寸、运动和受力约束 |
| positive_closure | 来源、关系、接口、受力、运动、状态和结构—行为—效果因果 |
| reverse_break | 干涉、失去接触、受力中断、运动冲突、参数缺口和效果失去归属 |
| TeachingRecord | 技术问题、目的、选择方向、明确教导、阻碍因素和合理成功预期 |
| EffectEvidenceCard | 受影响对象、结构/行为原因、比较基准、工况、范围覆盖和来源日期 |
| response_action、response_mode | 争辩、补正、补充核验或客户确认；ArgumentOnly/AmendmentBased |
| legal_conversion、prohibited_overclaims | 下游法律接口和禁止跳跃 |

机械路径的工程 FusionFeasible 仅在以下条件均满足时成立：

~~~text
构件来源闭合
∧ 连接/位置/配合关系保持
∧ 空间和接口可共同满足
∧ 接触、支撑或啮合连续
∧ 受力路径连续
∧ 运动方向和时序连续
∧ 状态转换连续
∧ 结构—行为—效果因果闭合
~~~

## ME-01 一体化机械配合

### 适用

用于多个区别构件通过位置、连接、配合、接触、运动或受力关系共同形成一个机械手段或效果的情形，特别用于回应“分别从 D1、D2 取得零件即可拼接”的主张。

### 不适用

仅能证明零件同时存在、没有共同作用关系、没有继承锚点或效果属于事后推测时，不得使用“协同”或“不可分割”。

### MBSE 与事实

重点核查 S/REL、B/STATE 和 E：

- 各构件在权利要求和说明书中的位置及连接；
- 接触、啮合、支撑、导向、密封、限位或传力关系；
- 结构如何改变运动或状态；
- 该行为如何产生技术作用；
- 效果是否覆盖整个权利要求范围。

### CombinationPath

记录“构件来源 → 安装/连接 → 接触或约束 → 运动/状态 → 效果”的每一步。Ω 不得把无来源的连接件、支撑件或参数作为默认补充。

### 正向闭合与反向断裂

正向闭合要求结构关系、受力和运动共同保持。反向断裂包括：零件位置改变、连接关系消失、接触/啮合失效、支撑不足、动作顺序改变或效果无法归因于组合结构。

### 证据与答复动作

TeachingRecord 记录各文件是否教导同一组合关系；EffectEvidenceCard 记录整体结构的比较基准和工况。可以争辩、补正或请求核验，但不能仅因多个区别特征相互靠近就写成协同效果。

### 对外转换

> 本申请的区别特征并非彼此独立的零部件并列，而是通过【位置/连接/配合/受力/运动】关系共同形成【机械手段】。沿该关系回放，特征 A 约束【对象】，特征 B 进一步产生【行为】，由此影响【技术对象/指标】。对比文件组合尚需证明上述关系在同一工作状态下能够连续保持。

## ME-02 对比文件不兼容

### 适用

用于审查意见要求将两个方案组合、替换或重新安装，但没有说明必要结构改造、接口条件和工作原理保持方式的情形。

### 不适用

若对比文件已经明确公开兼容接口、共同安装基准、相同运动关系或适配结构，应转向核查区别特征、效果强度或其他争点，而不作绝对不兼容论证。

### MBSE 与事实

分别记录 D0/Dk 的：

- 形状、位置、安装基准、接触面和连接形式；
- 功能前提和工作目的；
- 运动方向、时序、施力点和约束；
- 尺寸、节距、孔距、间隙、压缩量、轴径或模数；
- 审查员主张的加入、替换、重连或重排操作。

### CombinationPath

~~~text
D0 完整技术方案
  → Dk 提取的结构或关系
  → 安装/连接/参数调整
  → 组合后的空间、接口、受力和运动状态
  → 工作原理是否保持
  → 功能和效果是否保持
  → 仍存在的断点
~~~

### 正向闭合与反向断裂

正向闭合要求无空间干涉、接口可装配、接触/支撑/啮合连续、受力和运动一致、状态转换连续。反向断裂包括空间干涉、失去接触、支撑或啮合、受力路径中断、运动方向冲突、参数无来源或破坏原有功能。

### 对外转换

> D0 的【方案】以【结构/接口/工作条件】为前提，Dk 的【教导】以【另一结构/接口/运动关系】为前提。按照审查意见所述 CombinationPath，将 Dk 应用于 D0 至少需要【加入/替换/重连/调参】。该操作会影响【空间/接触/受力/运动/状态】；现有证据尚未说明如何保持 D0 的工作原理及本申请的整体效果。

不能把“需要改造”直接写成“必然不能组合”，应说明具体改造、证据状态和下游结合动机评价。

## ME-03 受力路径与运动路径区别

### 适用

用于动力源、施力点、传递件、约束反力、接触模式、运动转换或状态时序存在实质差异的情形。

### 不适用

仅有“拉与推”“滚动与滑动”等词语差异，未说明其对功能、结构或效果的影响时，不得直接命中。

### MBSE 与事实

受力路径至少回放：

~~~text
主动力源
  → 施力点/接触或啮合区域
  → 传递单元
  → 被驱动件
  → 约束/反力
  → 输出运动或状态
~~~

运动路径至少回放：

~~~text
输入运动
  → 中间运动
  → 方向、速度、行程或时序变化
  → 输出运动/状态
~~~

### 正向闭合与反向断裂

正向闭合要求动力源、传递件、约束和输出行为在组合后仍一致。反向断裂包括主动力源改变、接触模式改变、受力对象消失、运动方向或行程冲突、连续/间歇时序不一致或状态无法转换。

### 证据与答复动作

EffectEvidenceCard 绑定受力或运动变化与技术指标；TeachingRecord 记录对比文件是否教导该力流/运动流转换。若只能确定部分路径，应标为 I/Q，不得把附图推断当作确定事实。

### 对外转换

> 本申请中，力由【动力源】经【传递件/接触区域】作用于【被驱动件】，并在【约束】下产生【运动/状态】；D0/Dk 中的路径则为【另一力流/运动流】。该差异会影响【接触、支撑、运动或效果】。因此，审查员需要说明保持原工作原理的具体转换步骤，而不能仅以功能名称视为等同。

## ME-04 尺寸、节距、间隙与接口约束

### 适用

用于齿轮、链条、齿条、孔槽、导向、密封、轴承座、凸轮、滚轮或装配接口受到尺寸和工作条件共同约束的情形。

### 不适用

只有“大/小”“长/短”“紧/松”等无参照表达，或参数与相邻结构没有可证明的功能联系时，不得直接得出接口断裂。

### MBSE 与事实

每个参数必须记录：

- 测量对象和参照基准；
- 测量方法、工作状态和范围；
- 与相邻构件的配合关系；
- 对接触、啮合、导向、密封、支撑、运动或装配的影响；
- 权利要求是否确实限定该参数。

### 正向闭合与反向断裂

正向闭合要求参数、接口和装配条件共同可满足。反向断裂包括节距/模数不匹配、孔距或轴径不匹配、间隙导致失去导向、压缩量不足导致密封失效、参数调整没有来源或调整后改变工作原理。

### 对外转换

> 对比文件的【接口】受到【节距/孔距/间隙/压缩量/轴径】和【配合关系】共同约束。按照审查员路径需要同时调整【参数及相邻结构】，但材料尚未说明该调整如何保持【接触/啮合/密封/导向/运动】。附图比例不能单独证明未写入权利要求的确定数值。

## ME-05 传统替代方案仍不成立

### 适用

用于皮带替代齿轮、摩擦替代啮合、滚动替代滑动、弹簧替代刚性支撑、常规紧固件替代特定锁止等主张。

### 不适用

若替代后明确保持原结构关系、工作原理、接口和效果，应转向评价技术启示、常规选择或效果证据，不得仅凭替代名称反驳。

### CombinationPath

分别记录：

1. 被替代的构件或关系；
2. 替代后保留的结构；
3. 替代后改变的接触、受力、运动、状态和接口；
4. 替代是否需要新增安装或调参；
5. 是否仍解决同一技术问题并保持效果。

### 正向闭合与反向断裂

正向闭合要求替代件能在同一空间、接口、力流和运动条件下工作。反向断裂包括替代改变受力路径、运动方式、锁止顺序、密封压缩、接触模式或原有技术效果。

### 对外转换

> 即使存在【传统替代方式】，其最多改变【局部构件】，并不能自动形成权利要求所要求的【结构关系/受力路径/运动顺序/状态转换】。按照具体路径，替代后还需要【改造】；该改造的来源和成功预期仍需单独证明。

## ME-06 先有结构需求，再选择驱动/控制方式

### 适用

用于申请文件显示“工况或结构需求 → 结构方案 → 受结构约束的驱动/控制选择”，而审查意见将其倒置为任意驱动或控制替换的情形。

### 不适用

如果结构需求只在答复中事后提出，原申请文件没有相应工况、问题或结构依据，不得使用本模式。

### MBSE 与事实

必须建立 R→F→S/B 链：

- 工况或使用对象提出的结构需求；
- 空间、支撑、导向、密封、受力或运动约束；
- 传统驱动/控制方式为何不适配；
- 权利要求驱动/控制方式解决的具体结构约束；
- 申请文件和对比文件的支持位置。

### 正向闭合与反向断裂

正向闭合要求结构需求、结构关系和驱动选择形成连续因果。反向断裂包括传统方式仍可保持结构、驱动选择与结构需求无因果联系、驱动改变后破坏受力/运动或效果只由事后叙述产生。

### 对外转换

> 本申请并非先任意选择【驱动/控制方式】再附带形成【结构】；而是由于【工况】要求【结构需求】，该结构使传统【方式】受到【空间/接口/受力/运动】约束，因而选择【权利要求方式】。该因果关系应以申请文件和 CombinationPath 为依据，不等同于发明人的设计时间顺序。

## MechanicalCooperationCheck

当一项权利要求含有两组以上区别特征时，另行执行 MechanicalCooperationCheck：

- 分别建立每组特征的 R/F/S/B/E 链；
- 检查特征是否共享安装基准、接口、受力路径、运动状态或控制对象；
- 区分简单并列、局部替换和整体结构协同；
- 删除任一组特征后，检查结构、行为和效果是否仍能独立实现；
- 从属权利要求只在合法 DepPath 中继承特征，不得把兄弟分支拼入当前路径；
- 效果卡以完整机械方案和相同比较基准为对象。

## 机械子领域字段块

### 机构、传动与装配

构件层级、装配基准、连接方式、接触面、啮合、间隙、节距、孔距、轴径、运动自由度、行程、速度和装配顺序。

### 受力、支撑与密封

动力源、力的方向和大小（仅在有依据时）、传递件、约束反力、支撑位置、接触压力、密封压缩、泄漏路径和工况。

### 制造和调整

加工基准、装配公差、调整步骤、材料或表面处理（仅在权利要求和说明书中确有支持时）以及这些因素对结构—行为—效果链的影响。

## 证据、版本与答复护栏

- ArgumentOnly 保持 ClaimVersion 不变；不能把意见书样本或补充分析写成补正后的授权结果。
- AmendmentBased 新建 AmendmentEvent 和 ClaimVersion，重新生成 TA、区别特征、CombinationPath、Δ*、EffectEvidenceCard 和 ResponseTrace；旧分析标记失效或待重算。
- EffectEvidenceCard 没有比较基准、工况或范围覆盖时，只能支持有限或待核验效果。
- 对外答复不得出现 ME-01 等模式编号、R/F/S/B/E、D/I/Q/X、CombinationPath 或内部治理字段。
- 不能将模式命中、结构融合失败或 FusionFeasible=false 直接写成“具备创造性”。
- 最接近现有技术只有在会改变区别特征、实际技术问题、组合方向、效果归属或合理成功预期时才作为主攻争点。
- 不得从附图比例推断尺寸、材料、受力方向、接触状态或运动顺序。
- 不得把“工程上可以重新设计”写成“现有技术已经给出到达路径”。

## 文献资料的使用边界

- M-01 Tanaka：用于五类答复动作分类，以及机械案件中副引例被孤立零件化时的事实认定反驳；不能外推补正后结果。
- M-02 Dolder：用于多指标、可重复的创造性事实审计，不作为中国法定评分表。
- M-03 刘梅：用于“审查员认定—申请人答复—发明实质再判断”的过程链。
- M-04 张立得—牛继梅：用于限制最接近现有技术争点的篇幅，优先处理区别结构、技术问题和结合启示。
- M-08 Li：用于结构特征映射和组合分析方法辅助，不作为机械答审实证。
- M-07：仅作跨领域程序类比，不作机械领域结论。
