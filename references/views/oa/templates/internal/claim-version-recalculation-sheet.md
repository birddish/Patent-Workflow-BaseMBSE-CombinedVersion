# 内部模板：权利要求版本与重算登记

本模板只用于 `AmendmentBased`、复审补正或其他权利要求版本替代场景。它不随对外答复发送。

## 一、版本登记

| 项目 | 内容 |
|---|---|
| 原活动版本 | 【ClaimVersion】 |
| 新版本 | 【ClaimVersion】 |
| `supersedes` | 【原版本 → 新版本】 |
| 修改事件 | 【AmendmentEvent】 |
| 修改模式 | 删除 / 新增 / 概括 / 改序 / 参数调整 / 其他 |
| 修改后独立权利要求 | 【直接粘贴完整文本】 |
| 修改后相关从属权利要求 | 【直接粘贴完整文本】 |
| 原始支持原文 | 【直接粘贴】 |

## 二、影响闭包

| 受影响对象 | 原状态 | 受影响原因 | 新状态 | 是否重新生成 |
|---|---|---|---|---|
| 必要技术特征 | 【】 | 【新增/删除/关系变化】 | 【】 | 是 / 否 |
| 区别特征 | 【】 | 【】 | 【】 | 是 / 否 |
| 技术问题 | 【】 | 【】 | 【】 | 是 / 否 |
| `NB` | 【】 | 【】 | 【】 | 是 / 否 |
| `IS` | 【】 | 【】 | 【】 | 是 / 否 |
| `CombinationPath` | 【】 | 【】 | 【】 | 是 / 否 |
| 效果证据 | 【】 | 【】 | 【】 | 是 / 否 |
| 答复追溯 | 【】 | 【】 | 【】 | 是 / 否 |

## 三、重算门

```text
修改后权利要求
→ 必要特征/关系
→ 区别特征
→ 技术效果边界
→ 实际技术问题
→ NB/IS
→ CombinationPath
→ ResponseEvent/DecisionTrail
```

| 门禁项目 | 结果 | 证据/说明 |
|---|---|---|
| 原始支持已核验 | 通过 / 未通过 / Q | 【】 |
| 活动权利要求集合已冻结 | 通过 / 未通过 / Q | 【】 |
| 活动快照已冻结 | 通过 / 未通过 / Q | 【】 |
| 旧 NB/IS/ResponseTrace 已失效 | 通过 / 未通过 / Q | 【】 |
| 影响闭包已完成 | 通过 / 未通过 / Q | 【】 |
| 新 NB/IS 已重算 | 通过 / 未通过 / Q | 【】 |
| 组合路径可回放 | 通过 / 未通过 / Q | 【】 |
| 效果证据范围已核对 | 通过 / 未通过 / Q | 【】 |
| `recalculation_gate.passed` | `true` / `false` / Q | 【】 |

只要一个必要门禁未通过，提交状态就不得变为 `ready`。对外模板只使用修改后的权利要求，不把内部版本登记表直接复制出去。
