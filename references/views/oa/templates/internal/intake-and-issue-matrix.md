# 内部模板：案件准入与问题—动作矩阵

本模板只用于内部准备，不随对外答复发送。它的作用是确认入口、材料范围、审查意见问题和每个问题的唯一主处理动作。

## 一、案件准入表

| 项目 | 实际内容 | 状态 | 缺失/冲突 | 直接内容来源 |
|---|---|---|---|---|
| 案件入口 | 审查意见通知书 / 驳回决定 / 复审材料 / 其他 | 已确认 / Q |  | `office_action_text` / 决定原文 |
| 审查意见轮次 | 第【】次 | 已确认 / Q |  | OA 原文或事件 |
| 发文日 | 【】 | 已确认 / Q |  | OA 元数据或原文 |
| 答复模式 | `ArgumentOnly` / `AmendmentBased` / `Appeal` / `Interview` | 已确认 / Q |  | `response_events` |
| 活动权利要求集合 | 【】 | 已冻结 / Q |  | `active_claim_set_id` |
| 活动快照 | 【】 | 已冻结 / Q |  | `active_snapshot_id` |
| 主策略 | 【】 | 已确认 / candidate / Q |  | `primary_strategy_id` |
| 提交状态 | blocked / conditional / not_ready / ready |  |  | `submission_status` |

## 三、审查意见问题—处理动作矩阵

每个问题只能选择一个主处理动作。

| 问题标题（直接写明争议） | 审查意见原文 | 涉及权利要求 | 审查员依据 | 事实状态 | 主处理动作 | 对外模板位置 | 阻塞项 |
|---|---|---|---|---|---|---|---|
| 【审查员关于……的认定】 | 【直接粘贴】 | 【权利要求号】 | 【直接粘贴 D1/D2 原文】 | 支持 / 部分支持 / 不支持 / 无记载 / Q | 认可 / 争辩 / 修改 / 删除 / 分案 / 补充核验 / 客户确认 | §【】 | 【】 |

## 四、问题单元完整性检查

- [ ] 标题直接反映审查员指出的问题；
- [ ] 已直接粘贴审查意见或决定原文；
- [ ] 已直接粘贴本申请文本和对比文件原文；
- [ ] 已区分明确记载、工程推断和法律评价；
- [ ] 已写明审查员认知错误或确认不存在认知错误；
- [ ] 主处理动作与 `ArgumentOnly`/`AmendmentBased` 一致；
- [ ] 材料不足时保留 Q 或条件性；
- [ ] 没有把路径字段或引用编号当作实体事实。
