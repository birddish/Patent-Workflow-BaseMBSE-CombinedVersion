# 化工/生化/材料域答审规则

## 适用范围和边界

本文件供 答审/复审视图 的 biochemical mode 使用，覆盖化学、药物、生物技术、材料、组合物、化合物、制备工艺和用途发明。项目中的“化工领域”沿用 biochemical mode，不新建独立模式。

本文件只规定化工/生化技术事实、MBSE 建模和答复措辞。BC-01 至 BC-06、ChemicalClosureCheck、CombinationPath、TeachingRecord 和 EffectEvidenceCard 是工程分析接口，不是法律结论。pass、Q、fail、blocked 只表示资料或模型状态。

## S 节点与关系

| 节点/关系 | 最少记录内容 | 典型审查争点 |
|---|---|---|
| 化合物/结构 | 通式、取代基、立体构型、盐型、晶型、序列、材料结构 | 是否具体公开或仅公开通式 |
| 组分 | 必要/可选组分、纯度、来源、相态 | 是否真正公开同一组分 |
| 含量/比例 | 质量百分比、重量份、摩尔比、浓度 | 范围是否公开或有选择方向 |
| 工艺步骤 | 原料、加入、反应、分离、纯化、后处理 | 步骤顺序是否必要 |
| 工艺条件 | 温度、时间、压力、pH、溶剂、催化剂、气氛 | 条件窗口是否兼容 |
| 性能/效果 | 产率、纯度、活性、稳定性、选择性、粒径、黏度、药效 | 是否有基线和范围覆盖 |
| 用途 | 产品、用途对象、使用条件和技术作用 | 产品与用途是否混同 |
| Markush | 分支、优选项、实施例、排除项 | 具体选择是否有技术方向 |

组分名称、结构相似或功效标签不能代替身份、相态、条件、反应路径和效果证据。

## 化工/生化 R/F/S/B/E 最小链

至少建立：

~~~text
R 技术问题
  → F 组成/反应/制备/用途功能
  → S 组分、结构、材料和工艺条件
  → B 相互作用、反应路径、工艺顺序和状态变化
  → E 结构—性质、组成—效果或工艺—性能
~~~

产品、方法、用途和 Markush 权利要求必须分别固定当前 ClaimVersion；补正改变对象或范围时，旧 TA、NB、IS、EffectEvidenceCard 和 ResponseTrace 必须进入重算门。

## 模式路由和统一字段

| pattern_id | 适用问题 | 关键字段 |
|---|---|---|
| BC-01 | 组分、结构、相态或配伍不相容 | 身份、纯度、相态、溶剂、pH、稳定性 |
| BC-02 | 工艺条件、反应顺序或中间状态冲突 | 温度、时间、压力、pH、溶剂、催化剂、步骤 |
| BC-03 | 参数、比例或工艺窗口缺少选择方向 | 范围、端点、优选方向、效果和实验路径 |
| BC-04 | 对比文件存在明确反向教导 | 原文语气、对象、工况、避免原因和方向 |
| BC-05 | 组合效果不可合理预期或非简单叠加 | 对照、基线、机制、范围、重复性 |
| BC-06 | Markush/宽范围中的具体选择缺少方向 | 分支、先导、修改位置、优选项和成功预期 |

每次模式命中必须绑定 issue_id、claim_version_id、CombinationPath、TeachingRecord 和 EffectEvidenceCard。模式可并用，但不能把模式命中直接写成创造性结论。

## 各模式共用记录要求

每个模式至少填写：

- pattern_id、适用和不适用情形；
- R/F/S/REL/B/STATE/E 对象；
- D0、Dk、证据位置和各自技术作用；
- 被提取的结构、组分、条件、参数或用途；
- 混合、加入、替换、分离、调参、改序或用途转化操作；
- 允许的 Ω 适配及其来源；
- 身份、含量、范围、相态、条件、稳定性、选择性和工艺约束；
- 正向闭合和反向断裂；
- TeachingRecord、EffectEvidenceCard；
- ArgumentOnly/AmendmentBased 和答复动作；
- 技术事实、工程推断与法律评价的分层表达。

工程 ChemicalFusionFeasible 仅在以下条件均满足时成立：

~~~text
组分/结构身份保持
∧ 含量和范围共同可满足
∧ 反应条件共同可满足
∧ 工艺步骤和顺序连续
∧ 相容性、稳定性和选择性保持
∧ 结构/组成—性质或工艺—效果因果闭合
∧ 技术效果有比较基准且成功预期可说明
~~~

## 组合物与化合物规则

### 组合物

- 记录必要/可选组分、含量、比例、纯度、相态和开放/封闭式表述；
- 区分组分来源闭合与同一稳定体系闭合；
- 不能将多个文件分别公开的组分直接相加为完整组合物；
- 检查组分之间的溶解性、反应性、配伍、稳定性和相互作用；
- 效果必须能回溯到组分、含量、相态和工况。

### 化合物、药物和 Markush

- 记录结构式、取代基、立体构型、盐型、晶型、序列和先导化合物；
- 对通式、具体实施例、优选项和排除项分别建模；
- 检查选择位置、结构变化和效果之间的构效关系；
- 记录是否存在选择方向、筛选标准、反向教导和合理成功预期；
- 不能把通式包含某分支直接等同于具体化合物已被公开。

## 制备、合成和用途规则

### 制备/合成方法

- 记录原料、步骤顺序、加料方式、温度、时间、压力、pH、溶剂、催化剂/酶、气氛、纯化和后处理；
- 将中间体、状态、产物结构和表征作为 B/STATE 节点；
- 检查改序、调温、换溶剂或换催化剂是否改变产物、收率、纯度或选择性；
- 工程上可以重新寻找条件，不等于对比文件已经给出该工艺路径。

### 用途/药物

- 区分产品特征、用途对象、使用条件和技术效果；
- 不把产品已知直接等同于用途显而易见；
- 记录药效、毒性、稳定性、选择性、剂量和实验模型；
- 新增效果必须说明其申请日可得性和证据范围。

## 五类答复争点

| 争点 | biochemical mode 的处理 |
|---|---|
| 事实认定错误 | 核对组分、结构、范围、步骤、条件和效果是否真正公开 |
| 设计/选择事项认定错误 | 说明选择受结构—效果、配伍、工艺窗口或先导方向约束 |
| 缺乏结合动机 | 回放 D0/Dk 的问题、目的、选择方向、必要适配和成功预期 |
| 存在阻碍因素 | 说明失活、分解、沉淀、副反应、顺序冲突、选择性丧失或稳定性损失 |
| 有利/意外效果 | 以对比例、机制、范围覆盖、工况和测量方法为依据 |

最接近现有技术只有在会改变区别结构、实际问题、选择方向、效果归属或成功预期时才作为主争点。

## ChemicalClosureCheck

多组分、多结构或多步骤权利要求应执行 ChemicalClosureCheck：

- 各特征是否来自明确来源；
- 组分身份、含量、相态和纯度是否保持；
- 反应/工艺条件是否有共同可满足窗口；
- 步骤顺序和中间体是否连续；
- 稳定性、活性、选择性和产物属性是否保持；
- 效果是否由结构、组成或工艺链解释；
- 效果是否有比较基准、实验方法和范围覆盖；
- Markush 和从属权利要求的选择路径是否隔离。

该检查只输出工程事实状态，不直接输出创造性法律结论。

## EffectEvidenceCard 与 TeachingRecord

EffectEvidenceCard 至少记录：

- effect_id、受影响对象和客观指标；
- 结构/组分/工艺条件及其因果路径；
- 比较样品、对比例、工况、测量方法、样本和重复性；
- 实施例、实验数据或其他支持位置；
- 申请日可得性、权利要求范围覆盖和 D/I/Q 状态。

TeachingRecord 至少记录：

- teaching_id、D0/Dk 和问题；
- 先导化合物或起始组分；
- 修改位置、选择方向和技术目的；
- 明确教导、优选项、反向教导和必要适配；
- 阻碍因素、合理成功预期和证据段落。

## ArgumentOnly 与 AmendmentBased

- ArgumentOnly：保持 ClaimVersion 不变，针对事实、区别、相容性、工艺条件、选择方向、效果或成功预期进行答复。
- AmendmentBased：新建 AmendmentEvent 和 ClaimVersion，重新生成 TA、NB、CombinationPath、Δ*、TeachingRecord、EffectEvidenceCard 和 ResponseTrace；旧分析标记失效或待重算。
- 新增实验可作为后续证据，但不得冒充申请日已有公开内容。
- 未通过 recalculation_gate 时只能形成内部条件性稿件。
- 对外答复不得出现 BC 编号、R/F/S/B/E、D/I/Q/X、CombinationPath 或治理字段。

## 化工/生化域常见陷阱

- 组分分别出现在 D1、D2 不等于已公开同一组合物；
- 数值范围重叠不等于具体选择没有技术方向；
- 同一反应名称不等于工艺条件、顺序和中间体相同；
- 结构相似不等于性质、活性或药效相同；
- 效果更好不等于协同或不可预期；
- 单个实施例不能自动支持整个权利要求范围；
- 新增实验结果不能直接证明申请日已经公开该效果；
- Markush 通式覆盖不等于具体分支已被选择并获得成功预期；
- 反向教导或 ChemicalFusionFeasible=false 不等于法律上必然具备创造性；
- 不把社论、跨法域比例或自动评分写成中国案件成功率或法律结论。
