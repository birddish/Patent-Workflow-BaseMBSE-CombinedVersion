# 证据与推理控制

当论证依赖于机构、受力路径、几何条件、尺寸约束或所主张的技术效果时，使用本参考资料。

## 1. 命题类型

| 类型 | 含义 | 撰写处理 |
|---|---|---|
| E：明示事实 | 权利要求书、说明书、决定书或对比文件中直接记载 | 肯定性陈述并引用来源 |
| I：有界推理 | 在已陈述的工程前提下，从已识别的结构推导得出 | 陈述前提并使用限定性措辞 |
| A：主张 | 关于技术问题、动机或非显而易见性的结论 | 仅以 E/I 为基础；不得作为来源事实呈现 |

示例：

- `E`: “对比文件2记载链轮与链条啮合。”
- `I`: “在该啮合界面需要保持节距匹配这一前提下，链节的几何设计受到该接口关系约束。”
- `A`: “因此，对比文件2未给出为适配本申请结构而改变该传动路线的技术启示。”

除非文献或经论证的几何/运动学分析确定了具体限制，否则不要写"链节必然不能做大"。

## 2. 受力路径记录

对每个系统，分别记录：

| 项目 | 需确认的内容 |
|---|---|
| 主动力源 | 电机、皮带、齿轮、气缸、重力、弹簧等 |
| 驱动界面 | 齿啮合、摩擦接触、销连接、齿条啮合等 |
| 直接受力部件 | 在界面处受力的部件 |
| 被动部件 | 通过部件间关系被驱动的部件 |
| 传递与约束 | 拉/压、铰链、导轨、滚轮、接触反力 |
| 运动结果 | 转动、平动、导向回转、相对运动 |

仅在记录完整后才比较"拉""推""分散驱动"或"连续驱动"。若某点未公开，标注为 `[待核实]`；不要根据示意图印象填补空白。

## 3. 几何与尺寸控制

- 以明确参照定义内/外圆弧：轨道中心线、行进方向、曲线中心或部件包络。
- 区分路径条件与部件属性。例如，机架或轨道可能具有弯曲路径；链条本身并不会因此"具有"相同的弧，除非权利要求如此记载。
- 表述为"权利要求提供了容纳……的基础"，而非"权利要求要求大的部件"，除非尺寸已被权利要求或明确公开。
- 区分 `未公开`、`未建议`、`不能自然推导` 和 `物理上不兼容`。它们具有不同的证据门槛。

## 4. 发布前必答问题

1. 每个决定性事实句子的确切来源是什么？
2. 所有推理是否已陈述其前提并以条件式表达？
3. 实际技术问题的陈述是否引入了未要求保护或未获支持的参数？
4. 受力/几何断言是否混淆了观察到的附图特征与公开的机械关系？
5. 如果现有技术部件仅是惯用替代方案而非不可能方案，结论是否仍然成立？
