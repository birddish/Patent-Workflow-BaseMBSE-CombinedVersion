# 化工/生化/材料域论证模式

## 使用边界与答审链条

本文件供 答审/复审视图 的 biochemical mode 使用，覆盖化学、药物、生物技术、材料、组合物、化合物、制备工艺和用途发明。这里的“化工”沿用项目现有 biochemical mode，不新建独立 mode。

六类模式是选择器，不是固定话术，也不是创造性法律结论。只有在阶段二完成事实核实、阶段三形成可重放 CombinationPath 后才可选用。组分分别存在、结构相似、数值范围重叠或实验结果较好，都不能单独证明同一技术体系可以形成或具有创造性。

化工/生化案件统一沿以下链条工作：

~~~text
审查员主张
  → 对比文件原文、实施例、附图和实验数据
  → 当前 ClaimVersion 的 R/F/S/B/E 节点
  → 组分、结构、工艺、条件、用途或参数区别
  → CombinationPath（D0、Dk、组合操作、中间状态）
  → 身份、含量、相容性、条件、顺序、稳定性和效果闭合
  → TeachingRecord 与 EffectEvidenceCard
  → ArgumentOnly 或 AmendmentBased
  → 新权利要求版本及重新评价
  → DecisionTrail
~~~

化工/生化最小技术链：

~~~text
R 技术问题
  → F 组成/反应/制备/用途功能
  → S 组分、结构、材料和工艺条件
  → B 相互作用、反应路径、工艺顺序和状态变化
  → E 结构—性质、组成—效果或工艺—性能
~~~

## 权利要求对象和模式选择

### 权利要求对象分类

| 对象 | 关键评价内容 |
|---|---|
| 化合物/结构 | 通式、取代基、立体构型、盐型、晶型、序列或材料结构 |
| 组合物/配方 | 必要组分、含量、比例、纯度、相态、开放/封闭式表述 |
| 制备/合成方法 | 原料、步骤顺序、温度、时间、压力、pH、溶剂、催化剂、气氛和后处理 |
| 用途/药物 | 产品特征、用途对象、使用条件、剂量或技术效果 |
| 参数/性能 | 分子量、粒径、黏度、纯度、活性、产率、选择性、稳定性或药效 |
| Markush | 通式范围、可选分支、具体选择、优选方向和实施例 |

### 模式选择矩阵

| pattern_id | 主要断点 | 主要 MBSE 对象 | 不得单独推出 |
|---|---|---|---|
| BC-01 | 组分、结构、相态或配伍条件不相容 | S、REL、B、稳定性 | 组分名称不同即必然不能组合 |
| BC-02 | 工艺条件、反应顺序或状态不能共同满足 | B/STATE、条件和反应路径 | 温度或 pH 不同即自动具备创造性 |
| BC-03 | 参数、比例或工艺窗口缺少选择方向 | S、参数、E、TeachingRecord | 数值落入范围即必然显而易见或非显而易见 |
| BC-04 | 对比文件存在明确反向教导 | R/F、TeachingRecord、证据段落 | 任一不利描述都构成反向教导 |
| BC-05 | 组合后的结构—性质或组成—效果不可合理预期 | B/E、效果卡和比较基准 | “效果更好”即已证明协同 |
| BC-06 | Markush 或宽范围中的具体选择缺少技术方向 | S、结构分支、TeachingRecord | 通式包含某选择即公开了具体选择 |

化工/生化路径的工程 ChemicalFusionFeasible 仅在以下条件均满足时成立：

~~~text
组分/结构身份保持
∧ 含量和范围共同可满足
∧ 反应条件共同可满足
∧ 工艺步骤和顺序连续
∧ 相容性、稳定性和选择性保持
∧ 结构/组成—性质或工艺—效果因果闭合
∧ 技术效果有比较基准且成功预期可说明
~~~

## BC-01 组分、结构与配伍不相容

### 适用

用于 D0 的组合物、材料或反应体系与 Dk 教导的组分、结构、盐型、溶剂或相态在共同工况下不能形成稳定、有效或可加工体系的情形。

### 不适用

只证明组分名称不同、来源不同或功效描述不同，但没有反应、相态、稳定性、配伍或效果后果时，不得直接使用不相容结论。

### 必须核实

- 组分的确切身份、结构、纯度、盐型、晶型和相态；
- D0 的酸碱、氧化还原、极性、溶剂、含水量和稳定性前提；
- Dk 组分在该体系中的反应活性、溶解性、稳定性和配伍限制；
- 组合后是否产生沉淀、分解、氧化还原、副产物、失活或物性恶化；
- 不相容事实是文件明确记载、受限推断还是 Q。

### CombinationPath 与闭合

记录“D0 体系 → 加入/替换 Dk 组分 → 共同工况 → 中间状态 → 产物/组合物性能”。Ω 不得无来源地添加缓冲剂、稳定剂、相转移剂或其他关键补救步骤。

### 对外转换

> D0 的【组合物/反应体系】以【酸碱性/溶剂/氧化还原/相态】为前提，Dk 的【组分/结构】在该条件下会【沉淀/分解/失活/产生副反应】。按照审查意见路径将 Dk 引入 D0，需要增加【适配步骤】或改变【工况】，但现有证据尚未说明该操作能够同时保持【稳定性/活性/选择性】及本申请效果。

## BC-02 工艺条件、反应顺序与状态冲突

### 适用

用于温度、时间、压力、pH、溶剂、催化剂、气氛、加料方式、反应顺序或后处理条件不能共同满足的情形。

### 不适用

单一条件数值不同但能够在同一窗口内共同满足，或者对比文件已明确公开兼容条件时，应转向参数方向、效果证据或技术启示分析。

### 必须核实

- D0、Dk 的完整步骤和必要条件；
- 步骤之间的先后关系、停留时间和中间体；
- 催化剂、酶、溶剂、气氛和温度的有效窗口；
- 调整条件是否导致产物结构、收率、纯度、选择性或活性改变；
- 适配操作是否由文件或公知技术明确给出。

### 正向闭合与反向断裂

正向闭合要求条件窗口相交、步骤顺序连续、中间体可获得且目标性能保持。反向断裂包括催化剂/酶失活、反应物分解、选择性丧失、步骤顺序改变、后处理无法衔接或 D0 原有效果消失。

### 对外转换

> D0 的步骤【步骤】需要【条件 A】，Dk 的教导需要【条件 B】。二者合并还需要【改序/调温/换溶剂/加催化剂】；该操作会影响【中间体/产物/收率/选择性】。在未找到来源、接口和成功预期前，只能认定该工艺路径存在具体技术断点，不宜直接写成绝对不能实施。

## BC-03 参数、比例与工艺窗口的具体选择

### 适用

用于审查员将具体含量、比例、分子量、粒径、纯度、温度、pH、时间或工艺窗口认定为常规优化、有限实验或范围内任意选择的情形。

### 不适用

本申请范围是对比文件明确的优选范围、同一方向的直接缩小，且没有区别效果或选择障碍时，不得仅因范围名称不同主张非显而易见。

### 必须核实

- 本申请参数的测量对象、方法、单位、范围和端点；
- D0/Dk 的公开范围、优选方向、实施例和排除方向；
- 选择是否存在技术问题、筛选标准或结构—效果关系；
- 选择后的效果是否由对比例、多个实施例和完整范围支持；
- 是否存在合理实验路径和成功预期。

### 正向闭合与反向断裂

正向闭合要求参数选择有来源方向、共同工艺窗口可实现、效果在范围内可重复。反向断裂包括仅靠事后试验筛选、优选方向相反、范围端点无支持、参数改变造成不稳定或效果只覆盖单个样品。

### 对外转换

> 本申请选择【参数】范围【a-b】。D0/Dk 公开【范围及方向】，但未给出在【问题】下选择【a-b】的方向或筛选标准。该范围的效果应以【对比例/实施例/测量方法】和完整范围覆盖为限；不能因数值落入上位范围就当然认定为常规选择，也不能仅因存在差异就当然认定非显而易见。

## BC-04 反向教导

### 适用

用于对比文件明确要求避免、排除、降低、替换或不采用某组分、条件、结构、工艺顺序或反应方向，而审查员主张反向使用的情形。

### 不适用

一般性风险提示、未指向本案特征的背景说明或仅列举可能缺点，不足以构成反向教导。

### 必须核实

- 反向教导的原文位置、语气和适用范围；
- Dk 的教导对象、工况和避免原因；
- 审查员所主张的组合方向是否与该教导冲突；
- 是否有同一文件中的例外、替代方案或后续修正；
- 反向教导是否真正影响技术人员的选择和成功预期。

### 对外转换

> Dk 在【具体工况/对象】下明确教导【避免/不采用/降低】特征【X】，原因是【失活/副反应/稳定性/选择性】。审查员主张沿相反方向将【X】用于 D0，但未说明为何技术人员会忽略该教导，也未给出克服不利后果的路径。因此，该反向教导应作为 TeachingRecord 中的阻碍因素，与区别效果和合理成功预期一并评价。

## BC-05 协同效应与效果不可合理预期

### 适用

用于组合后的活性、稳定性、选择性、纯度、产率、粒径、黏度、药效或其他客观指标不是各来源效果的简单叠加，且有充分对照和因果机制支持的情形。

### 不适用

只有“效果更好”、单个实施例、无对照、测量方法不一致或效果不覆盖权利要求范围时，不得直接使用协同或不可预期结论。

### 必须核实

- D0 单独效果、Dk 单独效果和组合效果；
- 对照样品、样品制备、工况和测量方法；
- 组合效果是否大于或不同于简单叠加；
- 结构、组成、条件和效果之间的因果关系；
- 效果是否覆盖全部权利要求范围以及是否属于申请日可得材料。

### 正向闭合与反向断裂

正向闭合要求组合结构/工艺能够产生效果，比较基准一致且效果机制可解释。反向断裂包括效果被抵消、变化无法归因于区别特征、只在窄范围出现、数据重复性不足或新增实验改变评价对象。

### 对外转换

> 在相同【工况和测量方法】下，D0 的【基线】与 Dk 的【基线】分别产生【效果】；组合后取得【组合结果】。该结果与简单叠加的差异为【具体指标/机理】，且由【结构/组成/工艺】解释。若现有材料无法提供上述对照或范围覆盖，应改为有限支持或待核验表述。

## BC-06 Markush 与宽范围中的具体选择

### 适用

用于审查员以通式、Markush 范围、候选组分或宽工艺窗口覆盖本申请具体化合物、取代基、配方或条件的情形。

### 不适用

具体选择是对比文件明确的优选实施例、同一方向的直接替换，或效果与选择没有关联时，不得仅靠“通式很宽”主张非显而易见。

### 必须核实

- D0 的通式、分支、优选项、实施例和排除项；
- 本申请具体选择的位置、结构、立体构型、盐型、含量或条件；
- 选择是否有技术问题、筛选标准、方向或反向教导；
- 选择后的性质/效果及其范围覆盖；
- 本领域人员对成功的合理预期。

### 正向闭合与反向断裂

正向闭合要求具体选择在文献方向、结构兼容、工艺条件和效果链上均有支持。反向断裂包括从大量可能分支中无方向挑选、选择改变构效关系、选择导致稳定性/活性异常或效果仅由后见之明发现。

### 对外转换

> D0 虽公开通式【X】，但未给出从该通式中选择【Y】的优选方向、实施例或筛选依据。选择【Y】后产生的【性质/效果】与【结构/条件】存在可核验因果；本领域技术人员能否在申请日合理预期该结果，应结合 TeachingRecord、EffectEvidenceCard 和完整范围覆盖判断，而不能把通式包含直接等同于具体选择已被公开。

## ChemicalClosureCheck 与整体协同

当权利要求含有两组以上区别组分、结构或工艺特征时，另行建立 ChemicalClosureCheck：

- 分别建立每组特征的结构/组成—反应/工艺—效果链；
- 检查组分身份、含量、相态、条件和顺序是否共同可满足；
- 区分简单混合、已知配伍和真正相互作用；
- 检查删去任一组分或条件后，目标效果是否仍可实现；
- 检查效果卡是否以相同样品、工况、测量方法和比较基准为对象；
- 对 Markush 和多项从属权利要求，保持每条合法选择路径独立。

ChemicalClosureCheck 是工程事实检查，不是新的法定创造性要件。

## 化工/生化子领域字段块

### 化合物、药物和生物技术

结构式、取代基、立体构型、盐型、晶型、序列、先导化合物、结合位点、活性、选择性、毒性、稳定性、药效、剂量、实验模型和对照。

### 组合物、配方和材料

必要/可选组分、含量、比例、纯度、粒径、相态、开放/封闭式表述、混合顺序、相容性、储存条件、稳定性、流变性、强度、阻隔性或其他性能。

### 制备、合成和工艺

原料、步骤顺序、加料方式、温度、时间、压力、pH、溶剂、催化剂/酶、气氛、搅拌、纯化、结晶、干燥、后处理、中间体和产物表征。

### 参数与实验

测量对象、方法、仪器、单位、样本数、重复性、统计方法、对比例、实验条件、申请日可得性和权利要求范围覆盖。

## 证据、版本与答复护栏

- ArgumentOnly 保持 ClaimVersion 不变；不能把新增实验效果或补正后范围写成原版本结果。
- AmendmentBased 新建 AmendmentEvent 和 ClaimVersion，重新生成 TA、NB、CombinationPath、Δ*、TeachingRecord、EffectEvidenceCard 和 ResponseTrace；旧分析标记失效或待重算。
- 新增实验可以作为后续证据，但不能冒充申请日已经公开的技术效果；必须说明其用途和证据边界。
- 对外答复不得出现 BC-01 等模式编号、R/F/S/B/E、D/I/Q/X、CombinationPath 或治理字段。
- 不得把组分名称、结构相似、范围重叠、反向教导、协同模式命中或 FusionFeasible=false 直接写成法律结论。
- 不能把法域实务评论、统计比例或数据集模型表现写成中国案件成功率或确定的技术启示。
- Could-Would 只作为技术事实和组合路径形成后的下游规范接口。

## 文献资料的使用边界

- B-01 Ravula、Nirogi、Janodia：用于记录药物案件中的拒绝、补正、权利要求范围和审查过程关系；不能外推中国案件成功率。
- B-02 Tanaka：用于化学/生物领域五类答复动作分类和 ArgumentOnly 边界。
- B-05 Dhulap/Kulkarni：用于先导化合物、结构修改、意外结果和合理成功预期字段。
- B-07 Atkinson/Jones：用于区分结构相似、技术问题、选择方向和具体效果。
- B-08 Lu 等：属于实务评论，作为答复抓手目录，不作为统计实证。
- B-10 胡辉：用于把发明构思落实到结构/组成、工艺、机理和效果链。
- B-06、B-09：仅作跨法域背景或历史补充，不进入具体答复模式的核心证据。
